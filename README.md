# SIP Wake-up / Promo Call — সম্পূর্ণ ফ্রি (GitHub Actions)

প্রতিদিন সকাল ৬টায় (ঢাকা সময়) GitHub-এর ফ্রি কম্পিউটার আপনার SIP অ্যাকাউন্ট
থেকে কল দেবে — আসল Chrome ব্রাউজার দিয়ে, তাই প্রোমো ভয়েসও শোনা যাবে।
কোনো টাকা লাগবে না, কোনো কার্ড লাগবে না।

## খরচ

GitHub ফ্রি অ্যাকাউন্টে মাসে **২,০০০ মিনিট** ফ্রি। প্রতিদিন ১টা কল ~৪ মিনিট
হিসেবে মাসে ~১২০ মিনিট — অনেক কম, কখনোই লিমিট শেষ হবে না।

## সেটআপ (মাত্র ৫ মিনিট)

1. **github.com**-এ ফ্রি অ্যাকাউন্ট খুলুন (ইমেইল দিয়ে, কার্ড লাগে না)।
2. **New repository** বানান — নাম দিন যেমন `sip-wakeup-call`।
   Public বা Private যেকোনোটা চলবে।
3. এই ফোল্ডারের **সব ফাইল** রিপোজিটরিতে আপলোড করুন
   (Add file → Upload files) — `.github` ফোল্ডারটাসহ।
   `package-lock.json` ফাইলটাও অবশ্যই থাকতে হবে।
   সব ফাইল না থাকলে কাজ করবে না।
4. **Settings → Secrets and variables → Actions → New repository secret**
   - নাম: `SIP_USER`, ভ্যালু: `09649360000`
   - নাম: `SIP_PASS`, ভ্যালু: আপনার SIP পাসওয়ার্ড
   (পাসওয়ার্ডটা শুধু আপনিই জানবেন — আমি বা GitHub-এ আর কেউ দেখতে পাবে না।)
5. **Actions** ট্যাবে যান → **Wake-up / promo call** → **Run workflow**
   → নম্বর `01319779498` রেখে **Run workflow** চাপুন — একবার টেস্ট হবে।
6. টেস্টে কল এলে ফোন রিসিভ করে শুনুন — ভয়েস শোনা গেলে সফল!

## এরপর থেকে

- প্রতিদিন সকাল ৬টায় (ঢাকা সময়) অটো কল যাবে — কিছু করার দরকার নেই।
- কল না ধরলে বা মাঝপথে কেটে গেলে নিজে নিজেই আবার কল দেবে (সর্বোচ্চ ৩ বার), আর মেসেজটা কল চলাকালীন বারবার বাজবে — সর্বোচ্চ ২ মিনিট।
- GitHub-এর শিডিউল মাঝে মাঝে কয়েক ঘণ্টা দেরি করতে পারে (দেখা গেছে ৩-৪ ঘণ্টা দেরি হয়), এটা GitHub-এর দিকের ব্যাপার।
- যেকোনো নম্বরে প্রোমো কল দিতে চাইলে: Actions → Run workflow → নম্বর বদলে চালান।
- কোনো রানে ভয়েস না গেলে সেই রানটা লাল (failed) দেখাবে — লগে লেখা থাকবে কেন।

## কীভাবে কাজ করে

`call.js` (Playwright) GitHub-এর রানারে আসল Chromium খুলে
`https://call.shanto.info/` পেজে SIP রেজিস্টার করে কল দেয়।
কল রিসিভ হলে ঘুম-ভাঙানোর মেসেজ বারবার বাজে (সর্বোচ্চ ২ মিনিট); স্ক্রিপ্ট দেখে
আসলেই অডিও প্যাকেট গেটওয়ের দিকে গেছে কিনা — গেলেই সফল, না গেলে রান failed হয়।
না ধরলে বা মাঝপথে কেটে গেলে ৩ বার পর্যন্ত আবার কল দেয়।
